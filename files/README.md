# Easy-BS (Easy Building Simulation)
LLM/agent-assisted EnergyPlus model generation workflow.

============================================================
## IDF files produced by this repo
============================================================

This repository generates multiple EnergyPlus IDF files from the same parsed building description.
They differ in (1) how *orientation/rotation* is handled and (2) whether *simulation outputs* are configured.

------------------------------------------------------------
### 1) geom_bui_E+.idf  (Base EnergyPlus IDF / pre-rotation)
------------------------------------------------------------

Purpose:
- Primary EnergyPlus-ready IDF exported right after geometry creation + enrichment.

What it contains (generated by `geomeppy_generator.py`):
- Multi-storey geometry created via `add_block(..., zoning="by_storey")`
- Windows added on all sides per floor/orientation with equal-gap placement
- Basic constructions defined and assigned:
  - `WALL_Const`, `ROOF_Const`, `FLOOR_Const`
- Simple glazing system + window construction assigned to all windows
- Ideal Loads system added for each zone (`ZONEHVAC:IDEALLOADSAIRSYSTEM`)
- Inter-zone ceiling/floor adjacency linked between storeys (`ensure_interzone_pairs()`)
- Building orientation stored as:
  - `BUILDING.North_Axis = ROTATE_EP`

IMPORTANT:
- This file is saved BEFORE any vertex-coordinate rotation is applied.
- Geometry coordinates remain in the original axis system; orientation is mainly represented by `North_Axis`.

Typical use:
- Run EnergyPlus directly when you want a clean, “native” EnergyPlus model.

------------------------------------------------------------
### 2) geom_bui_SketchUp.idf  (Rotated geometry IDF / vertex-rotated)
------------------------------------------------------------

Purpose:
- Geometry inspection / visualization / interoperability workflows.

What is different:
- After saving `geom_bui_E+.idf`, the script rotates the entire geometry by:
  - `ROTATE_DEG = -ROTATE_EP`
- Rotation is applied to the *vertex coordinates* in XY:
  - Uses `idf.rotate()` if available
  - Otherwise uses manual rotation `_rotate_xy_vertices(...)` about the wall centroid

IMPORTANT:
- This is a *true geometric rotation* of coordinates.
- Useful when external tools or visual checks expect the building to be physically rotated in space.

Typical use:
- Visual validation (e.g., model preview), or alignment with CAD-like coordinate expectations.

------------------------------------------------------------
### 3) geom_bui_E+_modified.idf  (Output/run configuration variant)
------------------------------------------------------------

Purpose:
- Standardized simulation setup + reporting outputs for experiments.

How it is created:
- `energyplus_defi_output.py` loads an existing IDF (typically `geom_bui_E+.idf`) and modifies:
  - Removes all existing `OUTPUT:VARIABLE` and `OUTPUT:METER`
  - Removes all `SIZINGPERIOD:DESIGNDAY`
  - Sets `TIMESTEP.Number_of_Timesteps_per_Hour = 1` (hourly)
  - Defines `SITE:LOCATION` 
  - Sets `RUNPERIOD` to full year (Jan 1 → Dec 31)
  - Adds hourly zone output for each zone:
    - `Zone Mean Air Temperature`

Output name:
- `<input>.idf`  -->  `<input>_modified.idf`

IMPORTANT:
- This file mainly changes *simulation controls and outputs*.
- Geometry is inherited from whichever IDF you feed into the modifier.

Typical use:
- Batch runs or controlled experiments focused on hourly indoor temperature reporting.

------------------------------------------------------------
*The rules for multi-zone file naming follow the same principles as single-zone naming.
