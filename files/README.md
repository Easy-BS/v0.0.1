idf by LLM-based AI-Agent

This folder contains IDF files for the EnergyPlus simulation engine, jointly generated by LLM and AI-Agent. Each file is described as follows: 

The files differ by geometry orientation handling and simulation-output configuration, so they serve different purposes in the workflow.

geom_bui_E+.idf — Base EnergyPlus IDF (pre-rotation)

This is the primary EnergyPlus-ready geometry exported immediately after geometry creation and enrichment:

Geometry is created using geomeppy.IDF.add_block(..., zoning="by_storey") (multi-storey block split by storey).

Windows are generated on all sides with equal-gap spacing per floor and orientation (add_windows_all_sides()), and then assigned a glazing construction.

Basic opaque constructions are created and assigned (wall/roof/floor).

Zone-level Ideal Loads systems are added (ZONEHVAC:IDEALLOADSAIRSYSTEM for each zone).

Inter-zone adjacency between storeys is enforced by linking the ceiling of the lower zone to the floor of the upper zone (ensure_interzone_pairs()).

The EnergyPlus North Axis is set using BUILDING.North_Axis = ROTATE_EP to match the user-defined orientation.

Key point: this file is saved before any vertex-based rotation is applied. In other words, it keeps the original vertex coordinates produced by add_block(), while orientation is represented primarily through the North Axis setting.

Typical use: run EnergyPlus directly when you want a clean, “native” EnergyPlus model without manually rotating vertices.

geom_bui_SketchUp.idf — Rotated Geometry IDF (vertex-rotated for CAD/visual tools)

This IDF is generated from the same model but then undergoes a true geometric rotation (rotation of vertex coordinates in XY):

After saving geom_bui_E+.idf, the script rotates the geometry by ROTATE_DEG = -ROTATE_EP.

Rotation is performed using idf.rotate() if available; otherwise the code applies a manual vertex rotation (_rotate_xy_vertices(...)) about the wall centroid.

The intent is to produce an IDF whose geometry is physically rotated in coordinate space, which can be helpful when importing the model into external tools or doing visual validation (e.g., SketchUp-style coordinate expectations).

Key point: this file differs from geom_bui_E+.idf because the vertex coordinates themselves are rotated, not just the North Axis metadata.

Typical use: geometry inspection, external visualization workflows, or interoperability scenarios where coordinate alignment matters.

geom_bui_E+_modified.idf — Simulation Output / Run Configuration Variant

This file is created by energyplus_defi_output.py by loading an existing IDF (typically geom_bui_E+.idf) and modifying it for simulation settings and reporting outputs:

Removes all existing OUTPUT:VARIABLE and OUTPUT:METER objects.

Removes all SIZINGPERIOD:DESIGNDAY objects (to avoid design-day sizing periods).

Sets TIMESTEP.Number_of_Timesteps_per_Hour = 1 (hourly timestep).

Replaces/defines SITE:LOCATION.

Ensures RUNPERIOD covers the full year (Jan 1 to Dec 31).

Adds hourly output variables for each zone:

Zone Mean Air Temperature (Reporting_Frequency = hourly)

It then saves as:

<original>.idf → <original>_modified.idf

Key point: this file focuses on output definitions and run control rather than geometry. The geometry is inherited from the input IDF (most commonly the EnergyPlus-ready one).

Typical use: standardized experiment runs where you only need hourly indoor temperature outputs and consistent run settings.
